## Настройка проекта

[Пошаговая инструкция](docs/database-setup.md): установка PostgreSQL, окружение, создание базы через pgAdmin или команду, подключение, создание таблиц через Python и настройка PyCharm

После первого `git clone` или `git pull` создать в PyCharm окружение Python 3.12 в **`backend/app/.venv`**, выбрать его интерпретатором проекта и установить зависимости из `backend/app/requirements.txt`. Затем настроить локальную БД и `backend/app/.env` по инструкции выше. Окружение, `.env` и база не передаются через Git.

После настройки открыть [init_db.py](app/infrastructure/database/init_db.py) в PyCharm и выбрать **Run 'init_db'** в контекстном меню файла.

Используется интерпретатор проекта. При первом запуске создаются таблицы, при повторном добавляется служебная таблица состояний, если её ещё нет, и проверяется схема. Каждый обычный запуск синхронизирует тематический справочник из `app/tags.json`. Отдельная конфигурация запуска не требуется.

Код находится в `app/`, документация в `docs/`. Модели Pydantic находятся в `app/schemas/`, модели таблиц SQLAlchemy в `app/infrastructure/database/models/`

Для запуска API открыть `app/server.py` в PyCharm и выбрать **Run 'server'**. Swagger: http://127.0.0.1:8000/docs. Для проверки с синтетическими новостями сначала запустить `app/demo_data.py`.

Парсер и LLM подключаются через `NewsPipeline`, разметка компаний через `ProfilePipeline`. Методы описаны в [справочнике сервисов](docs/services.md).

Для реальных новостей и AI-разборов отдельно запустить `app/worker.py`. Он загружает RSS и котировки, размечает новости и профили, выполняет задания RAG-агента. API строит ленту по формуле, обученная модель не нужна. Ключ LLM используется только через API хакатона из `.env`.

Полный порядок: `init_db.py`, импорт выбранных компаний, `import_reports.py` при наличии подготовленных PDF, затем `server.py` и `worker.py` в двух конфигурациях PyCharm. Прямой запуск нового `newspaper_parser` для этого не требуется.

Фронтенд подключён к API. Реальная банковская авторизация и комплект развёртывания для сдачи не реализованы; вход в бэкенде демонстрационный.
