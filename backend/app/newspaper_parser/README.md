# Парсер газет и таблиц

## Содержимое папки

- `newspaper_parser.py` — скрипт импорта.
- `data/` — исходные PDF-отчёты и CSV-таблицы, скачанные из Google Drive.

По умолчанию парсер ищет поддерживаемые файлы именно в `data/`. Путь можно заменить параметром `--directory`.

## Что делает парсер

1. Читает PDF постранично. Если в PDF нет извлекаемого текста, на macOS использует встроенный Vision OCR. На других ОС для сканов нужны PyMuPDF и Tesseract с языками `rus+eng`.
2. Читает CSV потоком, не загружая целиком большие таблицы в память. Из таблиц формирует сводку: число строк и столбцов, а также агрегаты для распознанных числовых показателей.
3. Не сохраняет исходные строки CSV, синтетические ID, имена плательщиков/получателей или другие значения отдельных записей.
4. Записывает документы в `alfa_reports`, а текстовые фрагменты — в `alfa_report_chunks`. Для поиска используется существующая русская полнотекстовая индексация БД.
5. Считает SHA-256 файла. При повторном запуске уже импортированный файл не дублируется; незавершённая запись может быть обработана повторно.

Каждый PDF-фрагмент связан с номером страницы. Сводка таблицы записывается как один или несколько фрагментов. Статус документа становится `ready` только вместе с записью его фрагментов в транзакции.

## Запуск

Настройте PostgreSQL и `backend/app/.env` по [инструкции backend](../../docs/run.md), установите зависимости в окружение проекта, затем запустите из папки `backend`:

```bash
app/.venv/bin/python app/newspaper_parser/newspaper_parser.py
```

При необходимости обработать другую папку:

```bash
app/.venv/bin/python app/newspaper_parser/newspaper_parser.py --directory /path/to/files
```

Чтобы оставить оригиналы в `data/` после успешного импорта:

```bash
app/.venv/bin/python app/newspaper_parser/newspaper_parser.py --keep-files
```

## Что выводится

Для каждого файла скрипт печатает статус `inserted` или `already-present`, имя файла и число фрагментов. В конце выводится сводка счётчиков, например:

```text
inserted: Inflation_tracker_02.pdf (5 фрагм.)
already-present: df_Uid_payment_hack.csv (1 фрагм.)
Итог: already-present=1, chunks=5, deleted=1, inserted=1
```

Содержимое таблиц и сами тексты статей в консоль не печатаются. При ошибке указывается файл и причина; исходники остаются на месте, если обработка завершилась с ошибками. Импорт отдельных успешно обработанных документов уже зафиксирован, поэтому при повторном запуске они распознаются по хэшу и не добавляются повторно.

## Очистка исходников

По умолчанию после успешного импорта **всех** файлов парсер удаляет PDF/CSV/XLSX из обрабатываемой папки. Файлы удаляются только после успешной записи в БД. Используйте `--keep-files`, если хотите сохранить копии. Сам скрипт и этот README не удаляются.

Если БД не настроена или обработка любого файла завершилась ошибкой, парсер не удаляет исходники.
