# Разметка через LLM

Импорт: `from app.services.ai_agents import NewsTagger, ProfileTagger`

## Новости

`NewsTagger.tag(news: NewsForTagging) -> NewsFeatures`

- Вход: `news_id`, `title`, `text`, `published_at` с часовым поясом, необязательный `source_url`
- Выход: тот же `news_id`, тематические `tags` с `id` и `confidence`, отдельная `geography`, тип события, факторы, отрасли и краткое изложение
- ID новости задаёт приложение, модель не может его заменить
- При неизвестной географии используются `null` и пустой список, при отсутствии тем допустимы пустые `tags`
- Текст для модели ограничен 30000 символами, исходный текст в БД сохраняется полностью

Обычный запуск обработки выполняется через `NewsPipeline`, который сам получает новости и сохраняет признаки

## Профили

`ProfileTagger.tag(profile: ProfileForTagging) -> ProfileTags`

- Вход: `city` (может быть пустым) и `text` с известными фактами о деятельности и должности
- Выход: тематические `tags` с уверенностью и отдельная `geography`
- `ProfilePipeline.tag_company()` сохраняет автоматические темы, сохраняя ручные
- `ProfilePipeline.suggest_interests()` только предлагает темы пользователю

Схемы импортируются из `app.schemas.news` и `app.schemas.tagging`

## Настройки и справочник

Настройки в `app/.env`: `LLM_API_KEY`, `LLM_BASE_URL`, `LLM_MODEL_TAGGING`, `LLM_MODEL_CONTEXT`

Поддерживаемые ID: `qwen/qwen3.6-35b-a3b`, `z-ai/glm-5.3-flash`. Обе модели входят в список хакатона. Другой ID отклоняется до отправки запроса; добавление других разрешённых моделей требует проверки их ID у провайдера

`tags.json` используется обоими разметчиками. В таблицу `tags` загружается группа `business`; группы `city` и `region` используются для географии. Региональные коды в результате имеют вид `reg_77`, страна указывается двухбуквенным ISO-кодом. Географические признаки компании из банковского датасета не заменяются предположениями модели

`NewsService.sync_tag_catalog()` синхронизирует тематический справочник. Этот же шаг выполняется при обычном запуске `init_db.py`. Отключённые темы не включаются обратно

`add_bad_news(title, text, tags)` сохраняет последние 20 ошибочных назначений в `bad_news.json`. Блокировка файла работает на Windows и Linux. Это экспертные ошибки разметки, а не пользовательские дизлайки. Исходные записи файла являются синтетическими примерами

## Проверка

Бесплатные проверки из `backend`: `python -m unittest app.services.ai_agents.test_ai_agents`

Интеграционные проверки включаются переменной `RUN_DB_INTEGRATION=1`. Они создают отдельную временную PostgreSQL-базу и удаляют её после проверки; нужны права CREATE DATABASE

`manual_test.py` можно запускать напрямую из PyCharm. Один запуск делает один платный запрос и печатает `NewsFeatures`, без записи в БД

LLM-вызовы синхронные, из async-кода используется `asyncio.to_thread`. Автоматических повторных платных запросов нет

Разметчики не реализуют RAG-разбор: агент с поиском, самопроверкой и источниками подключается отдельно через `InsightService`
