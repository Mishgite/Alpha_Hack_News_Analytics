# Запуск в PyCharm

## Первый запуск

1. Открыть корень репозитория `Alpha_Hack_News_Analytics`, где находятся `backend`, `frontend` и `.run`
2. Выполнить [настройку БД и окружения](database-setup.md). Интерпретатор проекта: Python 3.12 из `backend/app/.venv`
3. В настройках PyCharm найти `Node.js` и выбрать установленный Node.js 22.12+. Для конфигурации `Frontend` нужна поддержка JavaScript/Node.js/npm в IDE
4. В терминале из `frontend` выполнить `npm ci`
5. Настроить `backend/app/.env`. Для локального фронта адрес API по умолчанию `http://127.0.0.1:8000`; при необходимости он меняется в `frontend/.env.local`
6. Убедиться, что служба PostgreSQL запущена. Один раз выполнить конфигурацию **БД - создать таблицы**
7. В верхнем списке конфигураций выбрать **Без воркера** или **Все сервисы** и нажать Run
8. Открыть `http://127.0.0.1:5173`. API: `http://127.0.0.1:8000/docs`

Конфигурации находятся в `.run` и доступны команде после получения этих файлов. Если список не обновился, переоткрыть проект. Python-конфигурации используют интерпретатор проекта, пути к чужому окружению в них не зашиты.

## Конфигурации

- **Frontend**: `npm run dev`, порт 5173
- **Backend**: `app/server.py`, порт 8000
- **Worker**: `app/worker.py`, сбор новостей, разметка, профили, биржа и AI-задания
- **Все сервисы**: Frontend + Backend + Worker параллельно
- **Без воркера**: Frontend + Backend параллельно
- **БД - создать таблицы**: `init_db.py`, создаёт таблицы и синхронизирует справочник тем в уже существующей БД
- **БД - проверить**: `init_db.py --check`, проверяет подключение и схему без создания таблиц

Без воркера доступны сохранённые новости, профиль, реакции, котировки и уже сохранённые разборы. Новые AI-разборы не выполняются. Уточняющие вопросы по готовому разбору обращаются к модели через API даже без воркера.

Воркер обращается к настроенной модели для новых данных и расходует бюджет. Параметры и лимиты: [worker.md](worker.md). Для своего файла настроек указать в **Run → Edit Configurations → Worker → Parameters**: `--config "путь/worker.json"`.

Общие конфигурации не создают БД, не устанавливают зависимости и не запускают службу PostgreSQL. При переходе между вариантами сначала остановить все ранее запущенные процессы через Stop: иначе порты могут быть заняты, а старый воркер продолжит работу. При одновременном старте фронт может открыться раньше API; после старта API повторить загрузку.

Если npm-конфигурации недоступны в установленной редакции IDE, фронт запускается из терминала командой `npm run dev`; Backend и Worker запускаются обычными Python-конфигурациями.

Формат общих запусков: [конфигурации PyCharm](https://www.jetbrains.com/help/pycharm/run-debug-configuration.html).
