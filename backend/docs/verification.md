- В отдельной живой проверке текст с попыткой подменить инструкции классификатора получил пустые теги и нулевую деловую значимость
- Две пары с новостью о ключевой ставке используют датированные материалы банка. В остальных случаях отсутствие подходящей банковской аналитики отмечается явно
- На восьми разных компаниях получено шесть разных первых троек ленты; общие новости о ставке и налогах пересекаются
- Загружены реальные RSS Банка России, ТАСС и Интерфакса. Повторная загрузка публикации возвращает прежний ID. Дословные копии и близкие пересказы связываются в события с сохранением отдельных текстов и источников; сильные переформулировки могут остаться раздельными. [Правила группировки](news-events.md)
- Полные статьи ТАСС на проверяемом компьютере возвращают HTTP 403, поэтому используются доступные описания RSS. Это сокращённый контекст, а не полный текст статьи. В текущей ленте Интерфакса после фильтра по экономике может не оказаться новых записей
- Linux-образ запускается без root. Проверены чтение трёх CSV, отсутствие `.env` внутри образа, повторный bootstrap без повторной разметки и доступность API
- Группировка событий: проверены близкий пересказ, разные суммы и единицы, города, отрицания и направления действий, разнесённые даты, одна карточка в ленте, сохранность текста при исправлении другого источника, ручное разделение, изменение ключа кеша и переиспользование разметки дословной копии. Разбор ограничен тремя новостными текстами и прежними 18000 символами. На 141 сохранённой публикации автоматических групп не обнаружено; платных вызовов при этой проверке не было

Это результаты конечной выборки, не оценка точности модели на всех возможных новостях. Проверка другим LLM не заменяет экспертную оценку. Доля рынка неизвестна без полного размера рынка; платёжные агрегаты описывают только предоставленные строки с неизвестным периодом и полнотой

Подробные ответы, трассы и исходные тексты проверки хранятся локально в `backend/data/validation/` и в БД, в Git не входят

## Повторить автоматические проверки

Из `backend`, с выбранным окружением проекта:

```powershell
$env:RUN_DATABASE_TESTS="1"
$env:RUN_DB_INTEGRATION="1"
python -m pytest app/test_quality.py app/test_news_events.py app/test_backend.py app/test_errors.py app/test_ranking.py app/test_profile_roles.py app/test_company_context.py app/test_container.py app/services/ai_agents/test_ai_agents.py -q
```

Из `frontend`:

```powershell
npm test
npm run build
```

Эти команды не вызывают платную модель. Для живой проверки запустить API и воркер по [инструкции](run.md), выбрать компанию, открыть ленту, запросить разбор, проверить цитаты и задать уточнение. Текущий бюджет и состояние процессов доступны в `/api/status` с токеном сессии


## Воспроизводимая оценка

[Команды, метрики и методика](quality.md). Контрольные случаи не обращаются к модели. Новые агрегаты компаний и исправленный поиск проверены локально и при генерации четырёх новых разборов. Проверка сохранённых цитат выполняется отдельно


Проверка расширений: 6 синтетических сценариев ранжирования и 6 пар для объединения событий прошли пороги. Реальный корпус: 5 из 5 тематических запросов нашли ожидаемый документ, 2 из 2 посторонних запросов вернули пустой результат. В сохранённых разборах последней проверки все проверенные цитаты присутствуют в сохранённых выдержках, ссылки на банковскую позицию имеют правильный тип. Новая экспертная разметка смысловой подтверждённости и пользовательские оценки пока отсутствуют

Контекст пересчитан для 50 компаний: отрасли отправителей известны у 43, получателей у 46. Повторная разметка моделью не потребовалась. Новые проверки не расходовали LLM-запросы

Повторная проверка расширений: отсутствие ссылок и отрицательные экспертные оценки нарушают пороги; сбой оценивания сохраняется в истории; история ограничена 30 результатами. После изменения кода проверка запускается заново. Пересчёт удаляет исчезнувшие платёжные признаки. Проверен импорт ручной расшифровки без сырых OCR-блоков

Текущая версия проверена на локальной БД и в Linux: существующая база обновляет контекст компаний и PDF при изменении файлов или обработчиков, второй запуск пропускает обновление. Все 50 профилей остались готовы без повторной разметки. API отвечает 200, heartbeat воркера актуален

Комплект проверен отдельно: исходники и закрытые данные распакованы в чистую папку, Linux-образ собран из неё. На PostgreSQL проверены создание 34 таблиц в пустой базе, повторная инициализация, валидация всех 50 выбранных компаний и девяти PDF, импорт PDF и реальный поиск. Повторный bootstrap на существующей БД пропустил разметку, API вернул health=ok. Полная первая разметка 50 компаний в новой контейнерной БД в этой проверке не запускалась; повторная платная разметка уже проверенных компаний не выполнялась
