# Импорт компаний

1. Настроить БД и создать таблицы по [инструкции](database-setup.md)
2. Положить `df_Uid_data_hack.csv` в `backend/data/companies/`
3. Открыть `backend/app/import_companies.py` в PyCharm и выбрать **Run 'import_companies'**
4. В консоли выбрать `1` для части компаний или `2` для всех
5. Для режима `1` ввести количество, например `100`

Используются интерпретатор проекта и подключение из `backend/app/.env`
Рабочая директория запуска не важна

Частичная загрузка выбирает первые N подходящих компаний в порядке CSV
Уже существующие компании входят в это количество, но пропускаются без обновления
Повторный запуск с `100` выбирает ту же сотню; запуск с `1000` расширяет выборку до первой тысячи
Если подходящих компаний меньше N, выбираются все подходящие

Запись идёт через `ProfileService.create_companies()` порциями по 100
При ошибке текущая порция откатывается, предыдущие остаются в БД; повторный запуск продолжит добавление без дублей
Платежи, связи и LLM-разметка этим скриптом не запускаются

Все строки с повторяющимся ID исключаются, даже если повтор находится за пределами выбранной части
Ошибки ID, флагов, числа полей и выручки также исключают строку
Пропуски сохраняются как неизвестные значения, ОКВЭД остаётся строкой
Поля профиля заполняются из CSV; название деятельности берётся из `MAINOKVED_NAME`
Исходные признаки, файл, его SHA-256 и номер записи сохраняются в `profile_json`
Коды регионов, стран и интересы не выводятся из названий автоматически

Отчёт запуска: `backend/data/import_results/<запуск>/`
- `summary.json`: выбранные, добавленные и пропущенные компании, состояние запуска
- `rejected.csv`: отклонённые строки с причинами и исходными значениями

Для проверки без подключения к БД в **Run → Edit Configurations → Parameters** указать `--check --limit 100`
Для запуска без меню доступны `--limit 100` и `--all`

CSV и отчёты скрыты `.gitignore`, скрипт находится в коде backend
