# Проверка готовности к демонстрации

25.10.2026 · ветка `dev-dasha_1` · локальные API, PostgreSQL и фронтенд

## Проверено

- 110 тестов бэкенда и 5 subtests без пропусков: отдельная временная БД и изолированные схемы PostgreSQL, API, сервисы, ранжирование, отказы и контракты LLM
- 31 тест фронтенда, проверка синтаксиса и production-сборка
- Вход и подборки всех 50 компаний через работающий HTTP API: пустых лент за 7 дней нет, повторов внутри подборки нет. В контрольном срезе получены 18 разных вариантов первых трёх новостей при одной роли
- Для `U_211`, `U_206`, `U_225` и `U_58` первыми идут разные отраслевые публикации. Совпадение общих новостей о ставке и налогах допустимо
- Частичный импорт первых 100 подходящих строк исходного CSV содержит все 50 компаний демонстрационного каталога. При проверке CSV рабочая БД не изменялась
- Первый запуск с одной синтетической компанией доступен через интерфейс. После импорта компаний хакатона каталог снова ограничен выбранными 50
- Реальный воркер получил RSS ЦБ, сохранил новости, разметил ожидающие записи через модель хакатона, импортировал 9 отчётов и обновил 500 котировок MOEX
- Пройден браузерный цикл: новость → задание → воркер → модель → сохранённый разбор → цитата → уточняющий вопрос. Для новости о мукомолах и компании `U_225` проверен частичный результат с явным отсутствием позиции банка
- Все 9 исходных PDF получены через защищённые API-маршруты, ответы имеют тип PDF и правильную сигнатуру
- На мобильных размерах 390×844 и 320×640 проверены навигация, лента, сохранение тем и биржа. Ранее также проверены 360, 430 px и горизонтальная ориентация

## Исправлено при подготовке

- Синтетическая компания из `demo_data.py` больше не теряется из каталога входа на пустой установке
- Пустая лента предлагает расширить период до 30 дней; при максимальном периоде ведёт к настройкам тем
- Агент адресует рекомендации сотруднику анализируемой компании, а не банковскому менеджеру
- Имена JSON-полей и коды признаков не допускаются в тексте выводов, условий и ограничений. При ошибке разбора используется предусмотренная попытка коррекции; дословные цитаты не переписываются
- В ответах на вопросы сохраняются переносы строк
- Обновлена [инструкция первого запуска](run.md), включая данные, PDF, лимиты модели и сценарий показа

Предыдущие исправления включают защиту от повторных AI-запросов и запоздавших ответов, обновление кеша при изменении новости, корректный учёт показов длинных карточек на телефоне, географию в формуле и привязку цитат к конкретным выводам

## Границы демонстрации

- Это локальное демо. Публичного HTTPS API пока нет; публикация фронта на GitHub Pages сама по себе не размещает бэкенд
- Вход демонстрационный, банковская авторизация не подключена. Счета и платежи обозначены как недоступные
- CSV и подготовленные PDF нужно получить отдельно. Они, ключи и локальная БД не передаются через Git
- Подборка содержит 104 реальные публикации за 19–25 октября. Позже для них потребуется расширить период; актуальные новости собирает воркер
- Рекомендации работают по формуле. Различие лент и технические тесты не доказывают качество для всех компаний; выводы исследования и ограничения описаны в [оценке ранжирования](ranking-quality.md)
- Анализ платежных связей и группы компаний, объединение похожих новостей разных источников и фильтр связанных эмитентов не реализованы
- Docker и общий README ранее исключены по решению команды. Полная проверка установки на другом чистом компьютере ещё не выполнена

Для показа запустить **Все сервисы** по [инструкции](run.md). Новые AI-разборы требуют работающего воркера, доступного шлюза и оставшихся лимитов
