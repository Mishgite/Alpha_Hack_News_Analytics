# Сторонние компоненты

## Программные компоненты

- Python 3.12, PostgreSQL 17
- Docker Compose: запуск контейнеров; Caddy 2: HTTPS и проксирование API
- Tesseract OCR, PyMuPDF, openpyxl: отдельный образ подготовки PDF и таблиц, не входят в основной процесс API
- FastAPI, Uvicorn: HTTP API
- Pydantic, pydantic-settings, python-dotenv: схемы и конфигурация
- SQLAlchemy, psycopg: доступ к PostgreSQL
- httpx, feedparser, Beautiful Soup, trafilatura, langdetect: сетевые источники и обработка публикаций
- pandas: табличные данные
- filelock: межпроцессная блокировка
- pytest: проверки бэкенда
- Node.js 22.12+, Vite: разработка и сборка фронтенда; интерфейс написан на JavaScript и CSS

Версии прямых зависимостей: [requirements.txt](app/requirements.txt), [package.json](../frontend/package.json). Транзитивные зависимости фронтенда зафиксированы в [package-lock.json](../frontend/package-lock.json). Условия использования и лицензионные файлы библиотек сохраняются в установленных пакетах.

## Модели и данные

- Генеративные модели вызываются через шлюз хакатона. Конкретные модели задаются в локальном `.env`, допускаются только ID из `ALLOWED_MODELS` в `app/services/ai_agents/_common.py`. Проверка реального разбора проведена с `z-ai/glm-5.3-flash`
- Внешние источники: RSS Банка России, ТАСС, Интерфакса и MOEX ISS. Заголовки, тексты, котировки и аналитические материалы принадлежат соответствующим правообладателям; наличие парсера не предоставляет права на их произвольное распространение
- CSV компаний, связей и платежей, PDF аналитики предоставлены организаторами. Оригиналы и результаты подготовки хранятся локально в игнорируемой папке `backend/data`, в публичную сборку не входят
- Поиск по отчётам: полнотекстовый поиск PostgreSQL; внешняя embedding-модель не используется
- Ранжирование: формула команды, обученная рекомендательная модель пока не подключена

## Смоделированные интеграции

- Вход в Альфа-Бизнес и проверка банковских полномочий имитируются демосессией
- Роль выбирается во внешней панели прототипа, доступ к реальным счетам и торговые операции отсутствуют
- `app/demo_data.py` и `frontend/src/demo` содержат синтетические примеры; локальный адаптер фронтенда исключён из production-сборки
- Наименование и визуальные элементы Альфа-Бизнеса используются в прототипе для кейса, это не официальный банковский сервис
