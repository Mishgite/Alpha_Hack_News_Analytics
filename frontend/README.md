# Фронтенд

Vite + JavaScript + CSS, статическая сборка с маршрутами через `#`

**[Настройка, совместный запуск и GitHub Pages](../backend/docs/run.md)**

- `src/app.js`: экраны и события
- `src/api/`: HTTP-клиент, сессия, запросы, обработка ошибок
- `src/styles.css`, `src/icons.js`: темы, адаптивная вёрстка и иконки
- `src/demo/`: синтетические данные для `npm run demo`, без API
- `tests/`: проверки интерфейса и клиента

Команды из `frontend`: `npm test`, `npm run build`, `npm run preview`

Перед `preview` остановить `dev`: оба используют порт 5173
