# Docker

[Настройка сервера, загрузка данных и отдельный фронтенд](../backend/docs/run.md#сервер-docker-и-отдельный-фронтенд)

`compose.yaml` запускает PostgreSQL, подготовку данных, API и воркер. Профиль `https` добавляет Caddy, профиль `ingest` доступен для ручного запуска универсального парсера

Настройки: `.env.example` → `.env`. Источники и интервалы воркера: `worker.json`. Данные компаний, PDF и секреты в Git и Docker-образ не включаются
